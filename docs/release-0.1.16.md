# Threadline 0.1.16

- 包含已经合并的 #63、#64、#65。
- 首页剩余与当日预计只统计所选日期的日程任务，排除 Daily 预计；空日程显示零预计。Daily 的预计保留在清单中，今日实际投入继续包含已记录的 Daily 分钟。
- 全项目按钮、菜单与主题采用统一交互状态。普通焦点使用背景和内部底线，强制色模式保留系统标识；首页右栏提供互斥选择菜单，任务更多入口可直接发现，危险操作独立分组。手机与触屏扩大真实命中区域，输入字号保持可读。
- 今日日程支持从杂乱文本智能提取任务、去重和匹配已有项目。确认表格按项目、任务、预计时长、开始时间和结束时间排列，可逐项编辑后导入；显示真实保存进度，部分失败沿用原任务编号与内容安全重试，成功项不重复提交。
- 设置新增个人 DeepSeek API Key 保存、替换和移除。密钥按账号加密保存在服务端，不回显到客户端；没有完成云端服务配置时，智能解析会提示服务不可用，手动创建任务仍可使用。
- Windows 完整工作台首次居中修正半 DIP 坐标取整偏差，保留原内容尺寸、位置记忆和一 DIP 验收阈值。原生窗口在 Renderer 完成权威状态同步后再显示，避免恢复时短暂显示过期界面。

## 数据与发布顺序

先核对目标 Supabase 项目的迁移状态，再按 [智能导入配置](ai-task-import.md) 应用 `202611190001_account_ai_credentials.sql`、配置服务端加密主密钥并部署 `ai-api-settings` 与 `smart-task-import`。新增表仅保存账号密文，不改变任务表结构；供应商密钥、加密主密钥和 service-role 不进入前端或安装包。

云端完成配置和认证验收后，发布 Web/PWA 与使用正式云配置构建的 Windows 客户端。以下状态均待补充实际证据，不能将本地模拟响应或静态构建当作生产联调通过：

- [ ] 个人 Key 保存/移除、认证解析与真实任务保存验收。
- [ ] Web/PWA 生产部署及线上版本核验。
- [ ] 正式配置的 0.1.16 NSIS 构建、安装/卸载与 0.1.15 → 0.1.16 数据保留验收。
- [ ] `v0.1.16` Release workflow、三个公开资产及线上更新源核验。
- [ ] 已安装 0.1.15 经检查、下载、确认重启升级到 0.1.16 的完整验收。

## 验证与已知问题

功能合并阶段已有 131 个文件 / 842 项单元测试、Web 与 Electron Renderer 构建的通过记录；完整 HIG 收集 112 项，其中 110 项通过、两项原有触屏专用用例在桌面条件下跳过。智能导入独立浏览器回归 8 项、Together E2E 11 项通过。原生居中保持原严格检查，已有两块连接显示器与完整开发壳原生回归通过记录。这些结果不替代本版本正式 NSIS 产物或生产服务验收。

计时并发回归已有失败，按用户要求暂缓处理。本版本未修复这些并发问题，不将相关 CI 失败描述为已解决，也不据局部测试通过声称完整业务 CI 全绿。保留的问题与证据见 [交互整改已知问题](apple-interactions-known-issues.json)。

正式 tag 必须匹配 `package.json` 的 `0.1.16`。Release workflow 先执行测试和静态 parity，再构建 NSIS、上传草稿并重新下载核对安装器、blockmap 与 `latest.yml`；核对通过后脚本会自动公开并设为 latest，没有额外人工等待点。安装升级验收应在触发发布前安排；当前不声称安装包、签名或线上升级已经通过。
