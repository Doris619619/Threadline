# 首次使用与个人设置

登录及工作区初始化成功后，未完成引导的新旧账号依次选择主题、性别和 Windows 自启动，再进入任务大厅。网页与 iPhone PWA 仅有前两步。各步可返回；账号可退出，Windows 保留原生关闭与最小化。

主题复用四套预览并即时保存在当前设备，保留字体与明暗选择，不按性别改色。性别必须明确选择：男生隐藏桌面侧栏、手机更多菜单及节律视图，停止该领域查询与订阅；女生恢复显示原记录。隐藏不会删除数据。在另一设备改为男生时，正在显示的节律返回首页。

## 保存边界

- `workspace_profiles` 保存 `gender`、`onboarding_completed_at`、`preferences_version`；旧账号新增字段为空，因此上线后补做一次。完成状态随账号同步，换设备不重复完整引导。
- `save_account_preferences` 仅接受当前登录账号，完成时要求性别；版本校验避免旧设备覆盖，重复目标可重试。读取、保存失败保留输入并提示重试，不伪造完成。
- 引导位于账号初始化之后、业务 Provider 之前。启动上下文的 `setPersonalizationActive` 暂停数据加载遮罩，完成后才加载工作台数据。账号切换销毁旧偏好会话，迟到响应不能污染新账号。
- 设置中的个人资料可修改性别。主题仍只存本机；测试与 Preview 使用独立的本地偏好适配器，默认已完成，生产无本地数据降级。

## Windows 自启动

仅带 NSIS 安装标记的 Windows 正式版支持。Main 固定当前可执行文件路径和 `com.doris619619.threadline` 注册表项，经可信主窗口 IPC 设置当前 Windows 用户的登录启动项。Renderer 只能调用读取、布尔开关、以后再选，不能指定路径或命令。

新安装默认关闭；只有明确开启才注册启动项。“以后再选”只保存本机提示已处理，不改已有开关。账号已完成引导但这台电脑尚未处理时，只询问自启动。本机记录独立于 Threadline 账号；已有选择在切换账号时保留。

“设置 → 桌面 → 开机自启动”以及窗口恢复焦点时回读系统实际状态，反映任务管理器中的禁用。写入后验证真实状态，失败可重试。启动后沿用现有窗口恢复及登录流程，不新增后台托盘模式。升级保留开关，真正卸载只清理本应用的启动注册表项；开发及目录 Preview 不写系统。

## 任务大厅与日程预计

首页标题为“任务大厅”，不显示原“安排、执行、记录今天”说明。其他栏目说明保持现有行为。

今日日程新增行、行内时间编辑和任务详细编辑在修改有效起止时间后，自动回填两者相差的分钟数。支持 `830`、`08:30` 等既有输入，重新修改时间再次计算。自动填入后可手动覆盖；仅改标题不重算历史预计，实际耗时不改变。缺失、相同或跨午夜的时间范围不自动计算，沿用现有保存校验。清空一端保留当前预计供继续修改，不迁移历史任务。

## 发布与验收

回归断言统一使用首页标题“任务大厅”；`workspace_profiles` 的表级权限只允许读取，初始化所需的 `owner_id` 列级 INSERT 及偏好字段写入限制由数据库测试覆盖。

引导的像素主题主按钮使用高对比深绿底，以引导作用域覆盖后加载的像素主题通用按钮规则，并直接断言最终计算颜色，避免 Linux 和 Windows 字体差异影响小号文字可读性检查；手机布局测试同时验证预计分钟自动回填与手动覆盖，桌面更新测试提供完整的引导阶段窗口接口。

先应用 `202609200001_account_preferences.sql`，再部署 Web 与发布 Windows 客户端；迁移新增字段和 RPC，不删除记录，兼容旧客户端初始化。0.1.8 按此顺序发布，CI 先验证隔离数据库中的权限与回归，再推送增量生产迁移。

自动验证覆盖账号隔离、完成约束、版本回退、保存失败、引导状态、原生开关控制及时间估算。浏览器检查四主题、手机窄屏、导航和键盘焦点。数据库 pgTAP 需要本地 Supabase；Windows 登录后自启、真实安装升级及卸载需要安装版实测，模拟系统 API 和编译成功不等同于已完成这些验收。

本次本地验证：72 个 Vitest 文件、357 项测试通过；桌面与 390px 手机的引导流程、日程新增及行内改时流程共 4 项 E2E 通过。四种主题的浅色/深色引导均通过严重等级的 axe 检查，代表截图位于 `docs/screenshots/release-0.1.8/`。Lint、类型检查、SQL 静态合同、Web 测试构建、Electron 生产配置静态构建及 Main/Preload 编译通过。本机 Docker 未运行，数据库测试由隔离 CI 执行；真实 Windows 登录启动、升级、卸载及真机 iPhone 验收仍需人工完成。发布结果以对应 PR 检查和 GitHub Release 为准。
