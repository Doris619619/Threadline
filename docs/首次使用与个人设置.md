# 首次使用与个人设置

登录及工作区初始化成功后，未完成引导的新旧账号依次选择主题、性别和 Windows 自启动，再进入任务大厅。网页与 iPhone PWA 仅有前两步。各步可返回；账号可退出，Windows 保留原生关闭与最小化。

主题复用四套预览并即时保存在当前设备，保留字体与明暗选择，不按性别改色。性别必须明确选择：男生隐藏桌面侧栏、手机更多菜单及节律视图，停止该领域查询与订阅；女生恢复显示原记录。隐藏不会删除数据。在另一设备改为男生时，正在显示的节律返回首页。

## 保存边界

- `workspace_profiles` 保存 `gender`、`onboarding_completed_at`、`preferences_version`；旧账号新增字段为空，因此上线后补做一次。完成状态随账号同步，换设备不重复完整引导。
- `save_account_preferences` 仅接受当前登录账号，完成时要求性别；版本校验避免旧设备覆盖，重复目标可重试。读取、保存失败保留输入并提示重试，不伪造完成。
- 引导位于账号初始化之后、业务 Provider 之前。启动上下文的 `setPersonalizationActive` 暂停数据加载遮罩，完成后才加载工作台数据。账号切换销毁旧偏好会话，迟到响应不能污染新账号。
- 设置中的个人资料可修改性别。主题仍只存本机；测试与 Preview 使用独立的本地偏好适配器，默认已完成，生产无本地数据降级。

## Windows 自启动

仅带 NSIS 安装标记的 Windows 正式版支持。Main 固定当前可执行文件路径和 `com.doris619619.threadline` 注册表项，经可信主窗口 IPC 设置当前 Windows 用户的登录启动项。Renderer 只能调用读取、布尔开关、以后再选，不能指定路径或命令。

新安装默认关闭；只有明确开启才注册启动项。“以后再选”只保存本机提示已处理，不改已有开关。账号已完成引导但这台电脑尚未处理时，只询问自启动。本机记录独立于 Threadline 账号；已有选择在切换账号时保留。

“设置 → 桌面 → 开机自启动”以及窗口恢复焦点时回读系统实际状态，反映任务管理器中的禁用。写入后验证真实状态，失败可重试。启动后沿用现有窗口恢复及登录流程，不新增后台托盘模式。升级保留开关，真正卸载只清理本应用的启动注册表项；开发及目录 Preview 不写系统。

## 发布与验收

先应用 `202609200001_account_preferences.sql`，再部署 Web 与发布 Windows 客户端；迁移新增字段和 RPC，不删除记录，兼容旧客户端初始化。当前工作只交付迁移文件，不自动操作生产数据库或发布版本。

自动验证覆盖账号隔离、完成约束、版本回退、保存失败、引导状态、原生开关控制。浏览器检查四主题、手机窄屏、导航和键盘焦点。数据库 pgTAP 需要本地 Supabase；Windows 登录后自启、真实安装升级及卸载需要安装版实测，模拟系统 API 和编译成功不等同于已完成这些验收。
