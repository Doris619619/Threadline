# Threadline 0.1.3

- 设置 → 外观新增「皮卡小屋」与「皮卡经典」，可分别搭配浅色、深色和独立字体。
- 像素家具、个人参考穿搭、白猫互动与短暂星光融入各页，保持原有任务布局。
- 经典主题采用奶油列表、橙色页签和绿色按钮；金色装饰集中在页签与弹窗，主页面没有整圈金色外框。
- 手机任务弹窗覆盖底部导航，保证编辑控件可点击。

发布后，0.1.2 安装版可在「设置 → 关于 Threadline」检查更新、下载并确认重启安装。旧 0.1.1 需手动安装新版以切换更新源；未安装的预览目录使用安装包升级。

发布流水线核验安装包、blockmap 和 latest.yml 后公开版本。真实设备上的下载与重启升级仍需使用者验收。
