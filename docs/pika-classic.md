# 皮卡经典

「设置 → 外观」新增第四套主题。皮卡小屋继续提供奶油／灰紫的柔和像素界面；皮卡经典参考用户提供的房间列表与公共场景窗口，采用金色角花、立体窗口边、橙色选中标签、绿色操作按钮和浅黄交替行。

## 窗口与文字

- 原有导航、任务区域、日程表、待安排池和 Daily 的位置不变，不添加房间横幅、额外仪表板或入口。
- 工作区保留原有应用边界，不加顶部金色横梁或两侧长金边。奶油色底、白色细边内容面板与金色括号标题融入原布局，任务不被向下推。
- 装扮与任务／项目编辑等真实弹窗使用独立金框、红色关闭方钮和绿色确认按钮；工作区不绘制假的关闭入口。
- 桌面正文为 16px，页面标题 24px／800 字重，面板标题 18px／700 字重，辅助文字 14px，次要说明 13px。单位使用 rem，手机正文保留 17px、页面标题 28px；字体选择仍独立，不强制替换用户字体。
- 主文字接近黑色，普通文字使用深棕橙；亮橙用于选中标签与图表。绿色立体按钮搭配高对比文字，错误／删除保留危险语义。
- 浅色采用奶黄 `#f6f1d4`、纸白 `#fffef8`、浅黄条纹 `#f8f4d0`；深色采用统一蓝灰底 `#242832`／`#292d36`、蓝灰面板 `#30343e` 和浅奶油文字。金边与括号使用独立哑金夜间素材，避免亮黄边和橄榄灰背景抢眼。

## 交互与复用

两个皮卡主题共用已生成的三套人物、16 种基础／个人家具、装扮选择和短特效。切换主题不会丢失装扮；同源窗口同步使用既有设备偏好机制。按钮按下、标签高光、换装散星和家具回应尊重减少动态效果，装饰不拦截操作。

`classic.css` 负责主题语义色、字体比例、窗框和预览；`classic-controls.css` 负责条纹列表、按钮、标签与装扮窗。共享像素 CSS 使用明确的 cottage／classic 选择器，不向默认蓝色或安妮雅应用游戏窗框。

主题枚举同时扩展解析、首帧引导、运行时图标、外观选择器和 Electron 受验证 IPC。独立金色图标在浏览器、启动／登录标志和 Windows 窗口保持一致；`frame.svg` 与图标进入离线预缓存。任务、Daily、项目、云仓储与数据库均无改动。

## 素材

`public/themes/classic/frame.svg` 与 `icon.svg` 根据参考窗口的材料和几何特征原创绘制；没有复制用户截图或游戏文字。`node scripts/build-cottage-icon.mjs classic` 将图标导出为 PNG 和 16–256px ICO，原 cottage 导出命令保持兼容。

## 验证

`e2e/classic.spec.ts` 检查主题独立保存、人物共用、任务首屏和字号、勾选／撤销、六个业务页的浅深色对比度、装扮窗口、四套主题选择器和 320px／200% 文字。同步回归 `e2e/cottage.spec.ts` 与 `e2e/appearance.spec.ts`。

真实图片与执行结果见 [验收记录](screenshots/classic/README.md)。浏览器模拟和静态构建不代表安装版 Windows、真实 iPhone PWA 或生产账户验收；经典主题本轮只交付本地预览。

配色分工、问题修正和实际对比度见 [视觉审查](pika-classic-review.md)。
