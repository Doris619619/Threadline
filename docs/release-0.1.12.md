# Threadline 0.1.12

- 计划与习惯页采用更紧凑、整齐的布局；皮卡经典使用暖白纸面，所有主题的习惯页统一展示今日打卡、统计概览、趋势图和每日状态。
- 阶段创建和详情追加支持选填预计分钟。桌面清单的任务、项目和估时同排对齐，手机自动换行；详情可切换预计/实际时间，以双层图展示项目和任务分布。
- 项目选择菜单支持键盘操作和较多项目时的搜索；输入框聚焦使用单层细边框，错误状态继续保留草稿和明确提示。
- 「结束今天」移至首页顶部统计面板，继续等待 Daily 保存后打开原收尾确认。主题切换后的时钟文字同步使用当前文本色。
- Windows 完整窗口跨屏回到较小屏幕、或可用工作区缩小时，恢复到可见范围，保留原来的窗口模式与设备偏好。

## 数据库与发布顺序

本版本包含已合并的 PR #53，基线提交为 `dad41f001d4574d9fe1a5be56e2f3b4cbca43c5a`。发布准备仅递增版本号并同步说明，不另改业务实现。

阶段估时要求 `202610020001_stage_task_estimates.sql`，沿用原 `tasks.planned_duration_minutes`，创建与追加仍在单次事务中完成；不复制任务。2026-10-03 发布前，关联生产项目的迁移清单已确认本地与远端全部一致，包含该迁移。

版本提交按 PR 流程检查并合并后，在合并提交推送 `v0.1.12`。正式 Release workflow 运行单元测试及 Preview/package-dir parity，使用生产云配置构建 `Threadline_0.1.12_x64-setup.exe`，同时生成 blockmap 与 `latest.yml`；上传草稿并回下载逐字节核对后才公开为最新稳定版。

## 验证与边界

业务基线的 [主线 CI](https://github.com/Doris619619/Threadline/actions/runs/37021272231) 中 Web、真实 Supabase、Preview 演示和 Windows Electron 全部通过。版本提交及正式安装包的结果以对应 PR 检查和 [0.1.12 Release](https://github.com/Doris619619/Threadline/releases/tag/v0.1.12) 为准。

公开资产核验包含安装器、blockmap 和更新元数据的内容、大小与校验值。自动化不替代实体双屏拖动、用户设备上的 NSIS 安装/卸载、两个已安装版本间的真实升级，或实体 iPhone PWA 验收。

实现细节与截图见 [界面精修](ui-polish.md)、[阶段计划](stage-plans.md) 和 [Windows 构建流程](WINDOWS_BUILD.md)。已有安装版可在「设置 → 关于 Threadline」检查更新，再由用户确认下载和重启；应用 ID 与数据目录保持原有配置。
