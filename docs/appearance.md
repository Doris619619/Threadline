# 外观与页面布局

在「设置 → 外观」选择默认蓝色、安妮雅或皮卡小屋主题，三者都支持浅色、深色和跟随系统。字体单独提供默认字体、思源黑体和思源宋体；切换主题不会改变已选字体。默认字体完整保留原设备字体栈，不下载 Apple 字体。

## 设计与交互

- 安妮雅浅色使用浅樱花粉底色、粉调奶油白卡片、玫瑰粉强调与深可可色文字，少量墨绿用于成功状态；深色使用暖紫灰表面、莓果粉强调与粉白文字。插画只出现在首页页头、主题预览、空回收站/任务池和认证插图区，不覆盖任务内容。
- 手机首页固定为标题行、日期工具栏两行；日期与日历图标是同一个原生日期选择入口，前后一天按钮在右侧。窄屏放大文字时插画让出标题空间，任务项目标签与任务名分行，主题选项也可变为单列。
- 规划的待安排池只有一个入口：手机底部托盘、桌面右侧栏。移除原月历内部跳转入口，月历图例保留；切日、安排和返回日期焦点沿用原规则。
- 项目页只显示「项目＋新建」页头，去掉副标题与固定留白；项目箭头固定在最后一列，距离卡片右侧 16px，不受归档标签有无影响。
- 设置概览和详情各自拥有唯一页标题。回收站保留一次说明和紧凑的行尾恢复按钮，长任务名换行；仍恢复到今天，不改变历史或统计。

## 实现与存储

`src/features/appearance/` 分别负责偏好校验、浏览器状态同步、字体加载、预览界面和主题视觉。根 `data-theme` 与 `data-font` 控制语义 token；尺寸与字体阶梯放在公共根定义中，不再依赖蓝色主题。日历专用色阶也由主题提供，图表沿用语义颜色，项目用户自选颜色保持不变。

偏好 `{ theme, font, colorMode }` 保存在 `threadline.appearance.v1`，只按浏览器 origin/设备保存，不随账号同步。同源标签页通过 storage 事件更新；记录损坏或字段无效时使用默认值，存储被禁用时保留本窗口选择并提示不能持久保存。没有数据库迁移。

根文档在首屏绘制前运行受限字段初始化脚本。Web 根布局传入请求 nonce；Electron 静态 HTML 使用现有构建脚本提取精确内容 hash。业务根挂载后监听偏好和系统色彩，不放宽 CSP，不引入 Electron 请求期 API。

字体通过本地 WOFF2 和 `font-display: swap` 按需加载，外观页面展示真实中文、英文与数字样张。首次打开该页面需要下载两种字体；普通工作台只请求当前使用的字体。下载/解码失败时使用默认字体并提示，显式重试创建新的 FontFace，防止已失败的 CSS 字体对象永久拒绝加载；晚完成的请求不能覆盖后续选择。

字体选择采用一个连续分组列表。名称统一使用设备默认字体和次要字号，只有样张展示字体差异；不重复风格介绍，也不为每种字体绘制独立卡片与重描边。淡粉选中底色和勾选图标表达当前选择，键盘焦点仍有清晰描边。

日期入口的整块点击、Enter 和空格会在用户手势内调用原生 `showPicker()`，避免桌面端只聚焦透明日期字段而没有打开日历。浏览器不支持或限制该 API 时保留原生输入行为；前后一天按钮继续独立工作。默认字体、颜色和日期导航无需额外配置，README 的使用路径保持适用。

字体和插画随 Web/Electron 一起分发，无运行时第三方请求。Service Worker 预缓存主题插画，字体在实际使用时缓存，成功加载过的字体可在离线时继续使用；尚未缓存的字体离线时使用默认字体。Electron 字体资源全部随应用本地打包。

Service Worker 在返回网络响应前同步复制响应，并通过 `event.waitUntil` 等待缓存写入。这样大字体不会因为响应先被消费或 worker 提前结束而漏写缓存；相同规则也用于现有同源静态资源和应用壳，跨域 Supabase 请求仍不接管。

## 资源

- 思源黑体：Adobe `source-han-sans` **2.005R**，`Variable/WOFF2/OTF/Subset/SourceHanSansCN-VF.otf.woff2`，本地 `public/fonts/SourceHanSansSC.woff2`。
- 思源宋体：Adobe `source-han-serif` **2.003R**，`Variable/WOFF2/OTF/Subset/SourceHanSerifCN-VF.otf.woff2`，本地 `public/fonts/SourceHanSerifSC.woff2`。
- 两者采用官方简体中文区域子集，缺失字符由设备字体回退；OFL 许可证随文件保存在 `public/fonts/`。文件名 SC 表示界面使用的简体中文版本，不表示完整跨地区 CJK 集合。
- 插画：内置 imagegen 生成透明安妮雅笔记本插画，压缩为 480px WebP，存放于 `public/themes/anya/notebook.webp`；详见同目录资源说明。

## 验证

自动验证入口：`tests/appearance-preferences.test.ts`、`e2e/appearance.spec.ts`，以及现有 UI 布局/无障碍矩阵。覆盖损坏偏好、首屏与客户端校验一致、真实字体加载、刷新和同源标签页同步、字体失败重试、明暗模式、单一待安排入口、箭头对齐和长标题回收站恢复。

截图与最终结果记录于 `docs/screenshots/appearance/README.md`。浏览器设备模拟和 iPhone WebKit 不等同于真实 iPhone PWA、系统 Dynamic Type 或安装版验收。此改动不包含生产部署、PR 合并或云端数据变更。

## 表单与配套图标

预计分钟只保留一个“待定”占位字，清空即待定；错误在提交时报告，不常驻展示时间规则。任务详情按任务名、项目、起止时间、预计/实际时长分组，取消为中性文字，保存为唯一主题主按钮。项目与任务列间距压至 3px。

`BrandIcon` 使用同步 data-theme 属性显示蓝/粉静态 PNG 与皮卡小屋 SVG，启动页、登录标志首帧匹配当前主题。原生窗口图标由 Main 验证主题枚举后切换，浏览器 favicon 同步更新。粉色 PNG 为内置 imagegen 对现有品牌图标的忠实换色版本，第二次编辑移除背景；最终提示为“保持粉色图案不变，移除棋盘背景并输出真实透明 PNG”。资源位于 `public/themes/anya/icon.png`，`node scripts/build-theme-icon.mjs` 仅转换大小和 ICO 容器，不重绘图案。

Windows 粉色安装包通过 PowerShell `$env:THREADLINE_DESKTOP_THEME='anya'; pnpm desktop:build` 构建，EXE、NSIS 与快捷方式使用 `icon-anya.ico`。同一选项支持 desktop:preview。新设备默认粉色，已有外观偏好优先；移除环境变量后恢复蓝色构建。Windows 已固定到任务栏的快捷方式可能保留安装时的图标，运行时窗口图标不改写用户快捷方式。

## 皮卡小屋

个人家园的窗帘、家具和紫色双马尾蓝裙穿搭被拆成像素图形，融入原有导航、任务面板、规划日期和弹窗。首页不放大房间、不挤占任务首屏；完整房间仅保留在主题缩略图与登录插画。桌面侧栏或手机「更多 → 我的装扮」可换装，原生模态框提供焦点隔离与 Escape 关闭。暖奶油底色、灰紫文字与少量粉蓝像素饰物在浅深色分别设计。人物按三套个人穿搭重绘为透明像素素材，七种个人家具分布到页面标题、面板标识与侧栏；换装、摸猫和点亮抓娃娃机提供会自动结束的特效，尊重系统减少动态效果。资源、存储和验收边界见 [皮卡小屋设计](pixel-cottage.md)。
