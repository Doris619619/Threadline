# Threadline 0.1.7

- 手机首页新增日程时，项目和任务名称等高对齐，开始与结束时间左右对齐；隐藏新增态的勾选占位，保留 44px 点击区域与 16px 输入字号。
- 习惯顶部直接切换昨天或其他日期；点击时间、图表日期和月历都只编辑选中的一项，更多设置默认折叠。
- 时间支持整段输入或粘贴 `23:48`、`00:12`、`01:40`，显示具体发生日期；凌晨仍按 04:00 分界归属所选那一晚，账号时区及历史原始时间规则不变。
- 习惯数据后台预读、并行获取并复用已加载范围；修复状态重新挂载后旧读取可能覆盖已确认记录的问题，账号缓存仍然隔离。
- Windows 完整窗口的关闭、最小化及窗口模式按钮始终留在顶部，无需滚回页面顶端。

本版无数据库迁移。合并后由 Vercel 发布 Web/PWA，版本 tag 触发 Windows 发布工作流；安装包、blockmap 与 latest.yml 一并发布，支持已有安装版更新。此次不在本机启动数据库，数据库回归由现有隔离 CI 执行。

审核重点是移动表单定位、跨午夜日期、首次保存与重试、陈旧读取、账号隔离和桌面窗口按钮。自动化检查不等同于用户真机手动升级验收。
