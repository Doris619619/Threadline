# 桌面交互与窗口形态

本文档描述首页今日工作台中新增的拖拽排程、荧光笔批注，以及 Windows 桌面端的三种窗口形态。Web/PWA 与桌面端共用同一套前端；Tauri 窗口尺寸与位置仅在桌面运行时生效。

## 任务拖拽

- 今日日程与无时间待办之间可拖拽任务，移动的是同一条任务记录，不会复制。桌面端请按住任务行最右侧的六点拖拽柄，移动到另一面板后松开鼠标。
- 从无时间待办拖入今日日程后，任务会进入待填时间状态并自动聚焦时间输入，不会猜测开始时间；待填任务会持久化、固定显示在日程最上方，用户可稍后填写或一直保留为空。
- 从今日日程拖回无时间待办后，会清除待填状态和全部排程字段（开始、结束、预计时长），其余字段保留。
- 荧光笔或橡皮擦激活时锁定任务拖拽与行内编辑，避免与批注手势冲突。

## 荧光笔与橡皮擦

- 工具入口位于今日日程标题栏；再次点击当前工具或按 Esc 退出批注模式。
- 笔迹以相对容器宽高的比例坐标持久化到本地存储，窗口缩放后仍对齐原内容。
- 非批注模式下图层不拦截点击，不影响勾选、编辑与拖拽。

## 桌面三态窗口

- **完整工作台**：使用原生 Windows 标题栏和系统最小化、最大化、关闭按钮；侧边栏六项分别进入首页、日程、项目、统计、复盘和设置。页面右上方的“窗口模式”菜单是三态切换入口。
- **迷你今日**：同样保留原生标题栏并始终置顶，只显示日期切换、今日已排程任务的时间、标题与完成勾选；不会显示项目、无时间待办或 Daily。
- **悬浮图标**：使用 Threadline 应用图标的无边框方形入口，始终置顶。单击恢复进入悬浮前的完整或迷你形态；拖动移动窗口；右键可进入完整工作台、迷你今日，或选择 56 / 72 / 88px 图标大小。

完整工作台、迷你今日和悬浮图标的尺寸与位置分别记忆；应用会在窗口移动或缩放后保存，悬浮前形态也会跨重启保留。浏览器环境无法调用 Tauri 窗口 API，但仍会通过 CSS 模拟布局变化，便于对照调试。

## 导航页面

- **首页**：今日执行总览，展示指标、今日日程、无时间待办与 Daily。
- **日程**：独立的时间安排页，显示待填时间任务和按时间排列的今日任务。
- **项目**：维护项目及其任务归属。
- **统计**：汇总任务和 Daily 的实际耗时、完成率与今日项目投入。
- **复盘**：按今日或本周查看完成、投入和任务流转。
- **设置**：提供窗口说明、窗口位置重置，以及“历史与回收站”二级页。
