# 桌面交互与窗口形态

本文档描述首页今日工作台中新增的拖拽排程、荧光笔批注，以及 Windows 桌面端的三种窗口形态。Web/PWA 与桌面端共用同一套前端；Tauri 窗口尺寸与位置仅在桌面运行时生效。

## 任务拖拽

- 今日日程与无时间待办之间可拖拽任务，移动的是同一条任务记录，不会复制。桌面端请按住任务行最右侧的六点拖拽柄，移动到另一面板后松开鼠标。
- 从无时间待办拖入今日日程后，任务会进入待填时间状态并自动聚焦时间输入，不会猜测开始时间；待填任务会持久化、固定显示在日程最上方，用户可稍后填写或一直保留为空。
- 从今日日程拖回无时间待办后，会清除待填状态和全部排程字段（开始、结束、预计时长），其余字段保留。
- 荧光笔或橡皮擦激活时锁定任务拖拽与行内编辑，避免与批注手势冲突。

## 荧光笔与橡皮擦

- 工具入口位于今日日程标题栏；再次点击当前工具或按 Esc 退出批注模式。
- 笔迹以相对容器宽高的比例坐标持久化到本地存储，窗口缩放后仍对齐原内容。
- 非批注模式下图层不拦截点击，不影响勾选、编辑与拖拽。

## 桌面三态窗口

- **完整工作台**：侧边栏、指标条、今日日程、无时间待办与 Daily。
- **迷你今日**：仅显示日期切换与今日日程，适合贴边查看。
- **悬浮图标**：缩小为圆形入口，点击恢复进入悬浮前的形态。

各形态的窗口尺寸与位置分别记忆。浏览器环境无法调用 Tauri 窗口 API，但仍会通过 CSS 模拟布局变化，便于对照调试。
