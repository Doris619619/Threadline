# 皮卡小屋

## 设计目标

让打开 Threadline 像回到自己在皮卡堂的家。视觉以用户提供的真实家园截图与日常穿搭为准：粉蓝渐变墙纸、白粉窗框、奶油地砖、花架秋千、星星地毯、抓娃娃机；人物保留浅紫长双马尾、头顶深色眼镜、冰蓝裙装与蓝鞋。奶油黄导航、淡紫动作色与晴空蓝房间底色，把房间与任务工作台连成同一套视觉。

房间是首页的主要视觉，正文仍使用可读的系统／思源中文字体。布局为桌面左侧问候与动作、右侧房间，下方保留真实日程、待安排与 Daily；手机先问候再房间，日程紧随其后。工作站不加入房间，完整首页可把小屋收为一行。

## 已实现的互动

- 设置 → 外观 → 皮卡小屋；保留原有蓝色与安妮雅，字体、明暗独立选择。
- 点击「摸摸小猫」或直接点房间中的白猫，出现短暂爱心与回应。白猫触控区至少 44 × 44px，键盘可聚焦；无声音、无后台循环动画。
- 「布置小屋」可替换中央空地上的星星坐垫、兔兔抱枕、绣球花盆。当前版本是三个固定位置摆件的替换，不是自由拖放家具编辑器。
- 当前工作日期的普通任务完成数与已完成 Daily 数共同决定地上的花，最多显示五朵。文字显示真实合计；取消完成会同步减花，不持久化另一套成就／货币账本。Daily 的统计口径沿用首页现有整项完成规则。
- 完成数增加时出现一次短反馈，刷新与首次读取已有完成数不会庆祝。切换日期会重置短暂互动状态，读取该日期的真实完成数。
- 布置与收起状态保存在 `threadline.cottage.v1`，主题仍使用 `threadline.appearance.v1`。两者都只在当前浏览器 origin／设备保存，同源标签页同步；不随账号同步。存储失败时保留本窗口的选择并提示。
- 夜间切换为深紫蓝工作台，小屋降低亮度。减少动态效果偏好关闭小屋动画，业务仍能正常操作。

## 实现与资源

- `cottage-home.tsx` 管理装饰、短反馈及本地存储，接收首页已计算的完成数；不读取或修改云端业务记录。
- `cottage-scene.tsx` 组合本地房间图片与可切换 SVG 摆件、花朵和 HTML 小猫按钮。
- `cottage.css` 单独维护主题语义 token、场景材料、响应式结构与动画。规划热力、Daily、表单、导航和登录／启动图标沿用同一 token 系统。图片外轮廓由展示层裁切，避免夜间出现浅色矩形底。
- 首帧 bootstrap 与客户端校验均接受 `cottage`。原生窗口 IPC 继续严格验证三项主题枚举，通过已有 `setIcon` 路径使用 `icon-cottage.ico`。
- `public/themes/cottage/personal-room.webp` 是内置 imagegen 根据两张用户参考图生成并重新构图的本地美术，1536 × 1024；只转换 WebP 编码，没有运行时图片服务。原始参考截图未加入仓库。
- `public/themes/cottage/icon.svg` 是原生矢量小屋与白猫图标，PNG 与 Windows ICO 由 `node scripts/build-cottage-icon.mjs` 生成。
- Service Worker 预缓存新主题房间与品牌资源，Electron 静态导出随应用分发。未增加库、字体或数据库迁移。

美术提示词与来源记录见 [资源说明](../public/themes/cottage/README.md)。初始网上参考包括 [4399 皮卡堂](https://my.4399.com/yxpkt/) 与 [官方游戏截图](https://picatown.com/)，最终个人视觉以用户截图为准。

## 验证入口与边界

- `tests/appearance-preferences.test.ts`：新主题的损坏输入、明暗／字体组合与首帧校验一致性。
- `e2e/cottage.spec.ts`：主题入口、真实完成／撤销、两种猫咪入口、摆件切换、刷新、收起／展开、跨标签页同步、浅深色无障碍、320px 和 200% 字号，覆盖桌面 Chrome、手机 Chrome、iPhone WebKit。
- 既有 appearance E2E 验证蓝色／安妮雅、字体加载、日期入口、规划和回收站行为。
- 截图与本次执行结果见 [验收材料](screenshots/cottage/README.md)。浏览器设备模拟不等同于真实 iPhone PWA 或安装版 Windows 验收；此分支不包含生产发布、自动更新发布或安装图标默认主题变更。
