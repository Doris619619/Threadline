# 皮卡小屋

## 体验目标

把皮卡堂的元素融入整个工作台，同时保持现有任务位置、信息密度与操作路径。第一版的首页大房间已经移除，不再要求先浏览装饰再向下滚动做事。用户家中的粉窗帘、白猫、花盆、书柜和穿搭被拆成可复用的像素图形。

## 像素风如何融入

- 导航：首页是粉顶小屋，规划是挂历，项目是书柜，洞察是望远镜，节律是唱片机，设置是梳妆镜。图标使用原导航的占位，标签不变；选中项呈现浅色游戏窗框。
- 任务与 Daily：保留原面板和行高，在现有边缘加入细木色窗框、日历／书柜／花盆标识。勾选框使用方形像素轮廓与阶梯勾，完成时出现一次短星光；取消完成、键盘操作、错误恢复仍由原业务控件负责。
- 规划：日期选中框、今天标识与小挂历采用像素材料，任务数量和热力统计维持原语义。颜色不是唯一状态指示。
- 项目与弹窗：项目色块成为物品格风格，共用按钮与表单采用细边框、内侧高光和按下反馈。完成／主要动作使用低饱和绿色；关闭、取消和危险操作保留原语义。
- 个人角色：桌面侧栏导航下方的空白处放小窗、花盆、角色和白猫，不插入主内容。手机通过「更多 → 我的装扮」进入，不新增浮动按钮或底栏栏目。
- 装扮：按用户新提供的穿搭图重新绘制三套细致像素人物，冰蓝裙装保留银紫长双马尾、头顶眼镜、蓝色嘴部配饰、合拢双手、分层裙摆与脚踝蝴蝶结；粉色外套和彩虹日常也有各自发型、帽子、包和鞋。透明 WebP 在浅深色均无背景方框。原生 dialog 支持焦点限制、背景隔离、Escape 和关闭后返回入口。
- 个人家具：电脑桌、黄心／绿星抱枕的粉沙发、樱花秋千、粉色抓娃娃机、星星电视柜、柠檬饮料、小熊共七款，融入现有标题、面板标识、空状态及侧栏。侧栏随当前页面换摆件，主内容不增加装饰行。
- 特效：换装出现六颗散开的星星；摸猫会轻跳、冒星；装扮窗口的抓娃娃机可点击点亮；侧栏悬停短暂闪星；完成任务出现三颗星；日期选中有短高光。所有动画自动结束，尊重系统「减少动态效果」，装饰与粒子不拦截鼠标。没有循环漂浮、声音、积分或抽奖功能。

## 配色原则

浅色以暖奶油白 `#faf7f2` 与纸白 `#fffdf7` 为大面积底色，文字使用暖灰紫 `#50454b`，浅木色边框限定在控件边缘。淡粉、浅蓝、紫色集中在图标和人物，避免大块紫底与强黄边竞争。主动作绿色 `#567957`，配奶油白文字；任务的错误、成功和项目自定义颜色保持各自含义。

深色单独使用灰紫底 `#262431`、面板 `#302d3b` 与浅暖文字，避免简单反相。逐页检查首页、规划、项目、洞察、节律、设置、外观和装扮的实图与 axe 对比度；自动对比度通过不代替视觉检查。

## 架构与存储

- `cottage.css`：明暗语义 token、品牌与外观预览；`cottage-details.css`：全应用控件与像素材料；`cottage-wardrobe.css`：侧栏与装扮窗口；`cottage-furnishings.css`：个人家具分布与有限时长的粒子效果。
- `cottage-sprite.tsx`：导航组合、装扮图片；`cottage-furniture.tsx`：家具与星光展示。`pixels.svg` 保留九种基础图形，`furniture.svg` 新增七种个人家具，symbol 用于 React，view fragment 用于 CSS。`avatar-*.webp` 是三张 256 × 355 透明图，合计约 218 KiB，没有远程资源或新依赖。
- `cottage-companion.tsx`：仅当前主题挂载，装扮保存为 `threadline.cottage.avatar.v1`，同源窗口与当前页入口同步。存储失败时提示并保留本次选择；损坏值回退冰蓝裙装。
- 旧版 `threadline.cottage.v1` 房间布置记录原样保留但不再读取，没有清空用户存储。大房间、三种摆件和完成花朵不再进入首页。
- 任务、Daily、日期、业务仓储和云端同步逻辑不变；没有数据库迁移或成就／货币账本。紧凑工作站只采用主题控件，不挂载角色面板。
- 本地 sprite 进入 Service Worker 预缓存；房间 WebP 仅用于外观缩略图／登录页，来源与原生成提示见 [美术记录](../public/themes/cottage/README.md)。用户原截图未进入仓库。

## 验证

`e2e/cottage.spec.ts` 对比蓝色与皮卡主题的首条任务坐标和宽度，检查真实勾选／撤销、三套装扮、刷新、跨标签页、焦点返回、320px 与 200% 文字、各业务页深浅色对比度，以及人物加载、侧栏家具变化、动画有限次数、粒子点击穿透和减少动态效果。桌面 Chrome、手机 Chrome 和 iPhone WebKit 分别运行。

实图与结果见 [验收材料](screenshots/cottage/README.md)。浏览器模拟不等于真实 iPhone PWA 或安装版 Windows 验收；本次不包含线上发布与新安装包。
