# Threadline 统一交互系统

## 范围与依据

整改从 2026-11-19 拉取的最新 `origin/main`（`6b3b79c6217e9acefa35ceaa7419de0cbb9df1f6`）开始，使用独立 worktree 与 `ui/20261119-apple-interactions` 分支。既有统计口径修复 PR #63 保持独立，本分支不合并其它工作。

用户已确认方案 A，并在原演示 HTML 遗失后再次指定直接按 Apple 应用的按钮交互实施。P1 参考采用圆润菜单、附近定位、分组、选中对勾和清晰文本。原资料包中「只输出计划」与「保留传统焦点环」已由本次用户要求覆盖。

本次实际读取四篇 Apple 最新原文（2026-11-19），参考原则如下；这些原则不代表 Apple 对 Web 像素值的强制规定，也不意味着本产品获得 Apple 认证：

- [Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons)：区分主要、次要与危险操作，提供明确按下反馈，保持足够命中区域和进行中反馈。
- [Pointing devices](https://developer.apple.com/design/human-interface-guidelines/pointing-devices)：指针、触摸与键盘能力等价；隐藏操作必须可发现；命中区域和指针效果不应制造精度负担。
- [Pop-up buttons](https://developer.apple.com/design/human-interface-guidelines/pop-up-buttons)：用于平面互斥选择，显示当前值，选择后关闭。
- [Menus](https://developer.apple.com/design/human-interface-guidelines/menus)：清楚描述动作，按任务分组；需要更多输入的动作使用省略号；不可用状态仍可辨认。

## 架构和设计契约

Web/PWA 与 Electron 静态前端共用组件和交互状态。数据、Supabase、RPC、任务完成/移期/回收站、Daily、计时账本和原生窗口权限保持原边界；不引入新的 UI 依赖。

`src/styles/tokens.css` 定义状态颜色和时间，`src/styles/interactions.css` 在业务与主题 CSS 后加载，保证普通、主要和危险操作遵循同一优先级。各主题由已有 surface/accent/text 语义颜色派生反馈，经典与小屋美术资产继续保留。

| 状态           | 反馈与语义                                            |
| -------------- | ----------------------------------------------------- |
| Default        | 保留控件原有常态层级和主题材质                        |
| Hover          | 只在支持悬停的设备上轻微改变背景；不缩放              |
| Pressed        | 按下时背景再深一档，80ms 反馈，松开后回到真实状态     |
| Selected       | 持续浅选中背景、对勾或原有选择标记，不能由 hover 冒充 |
| Expanded       | 菜单展开期间保持浅背景，语义与 `aria-expanded` 一致   |
| Disabled       | 降低强调并保留原禁用语义；不可出现可执行状态          |
| Busy           | 继续使用保存屏障、禁用和忙碌反馈，阻止重复提交        |
| Keyboard focus | 可见背景和内部底线；普通模式不使用外围轮廓            |

输入使用边框或内部底线表达编辑焦点；隐形原生日期/复选框把反馈传给可见标签。强制色模式可能不显示背景和阴影，允许系统 Highlight 轮廓作为必要例外。减少动画偏好关闭不必要过渡。

菜单容器使用功能性的柔和半透明材质、短动画和阴影，与内容分离；互斥选择、动作菜单和复杂表单仍采用各自语义。浮层使用浏览器顶层与真实视口边界，保留 Escape、外部点击、方向键、Tab 退出和焦点归还。

- 状态：普通/主要/危险按钮默认、hover、按住、松开、选中、展开、禁用、busy 与键盘焦点。

- 外观：blue、anya（粉色）、cottage、classic，分别浅色与深色，强制色和减少动画。
- 模块：首页/日程/待安排、Daily、计划/项目/阶段、日历、习惯、节律、洞察、工作站、计时器/计时站、设置、认证、初始化、Together 与弹窗。

- 保留业务 E2E、Lint、TypeScript、Web 与 Electron 静态前端构建；不制作 NSIS、不执行数据库迁移。
