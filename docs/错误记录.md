# 错误记录

每个问题只记录问题、原因、解决三项，后续按日期追加。

## 2026-10-18 计时完成后卡片延迟消失

- **问题**：点击计时卡片的完成勾选后，卡片停留一会儿才消失，按钮暂时不能操作，感觉像卡住了。
- **原因**：卡片只有在云端保存成功后才移除，保存期间按钮被禁用，界面反馈受网络和服务器响应速度影响。
- **解决**：点击后立即收起卡片并让其他卡片补位，后台保存完成状态和耗时；保存失败时恢复卡片并提示重试，保留原耗时，避免丢失或重复记账。

## 2026-10-21 多标签并发计时覆盖

- **问题**：两个标签页同时暂停不同计时器，其中一次暂停可能丢失。
- **原因**：整组计时器的读取和写回没有跨标签独占保护，后一次写入覆盖前一次结果。
- **解决**：以同账号 Web Lock 串行读取、校验和保存计时状态，完成前先确认本机待提交记录，补充三路交错及双标签并发回归。

## 2026-10-21 时钟回拨后续时无法保存

- **问题**：倒计时到时后系统时间回拨，再续时可能生成重叠时段，完成保存被拒绝。
- **原因**：续时直接使用回拨后的时刻，没有限制为不早于上一运行段终点。
- **解决**：续时先冻结旧时段，再保护新启动锚点；补充追上锚点前后暂停、重复续时和缓存恢复测试。

## 2026-10-21 重复午夜漏算计时

- **问题**：午夜夏令时回拨时，已保存的原始耗时可能没有进入统计。
- **原因**：数据库将重复午夜解析为第二次午夜，排除了第一次午夜后的运行区间。
- **解决**：新增向前迁移，以自然日首次有效瞬间拆分时段，保留原始记录并补充重复午夜、跳过午夜和跨日回归。

## 2026-10-22 生理期回归读取外观过渡中间帧

- **问题**：完整 WebKit 回归在生理期表单操作成功后，报告深色月历的外月数字和起止文字对比度不足。
- **原因**：共享日历样式为节律日期按钮定义了背景色过渡；该用例切换系统深色后立即运行 Axe，读取了按钮背景的插值色。同文件字体回归已有的主题属性和真实动画完成等待没有覆盖这个完整表单用例。
- **解决**：等待根主题属性更新并完成实际 CSS 过渡后，再执行原有全部 Axe 检查；保留既有配色，保存浏览器计算的数字、文字与背景颜色供核对。
