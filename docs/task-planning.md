# 任务规划

规划取代旧项目投入月历，内部导航仍为 `calendar`。首页负责当日执行；规划的日期是独立页面状态，默认本地今天，浏览不会更改首页日期。

## 页面行为

- 手机：周一开头的周条、当天清单、底部可展开待安排池；月份按钮打开底部选日面板。
- 桌面：1024px 起左侧常驻月份和待安排，右侧周条和日清单；较窄窗口使用手机布局。
- 月份和周条计数为当前日期的 active 普通任务，包含完成项；待安排、放弃、回收站和 Daily 不计入。热力四档为 0、1–2、3–4、5+；今天下划线、选中日期描边与密度颜色分开表达。
- 清单按有时间、未定时间、已完成分组。有时间按开始时间升序；已完成默认折叠。预计只累计未完成任务，缺少估时单独标记。
- 新建固定使用打开表单时的浏览日期；过去日期可查看和编辑已有任务，但不提供新增、安排目标。任务可编辑、完成、改期或退回待安排。
- 待安排保留重要/普通分组，显式按钮显示目标日期；提交中防重复，失败保留原数据并显示错误。编辑、改期和月历使用共用可访问模态组件。

## 持久化与兼容

普通字段使用新增 `saveTaskConfirmed(task)` 命令，等待数据库确认后更新缓存；任务表单继续复用现有校验。安排、改期、退回使用原子 `transition_task`。

迁移 `202609060001_task_planning.sql` 新增四参数 RPC：`p_task_id`、`p_transition`、`p_target_date`、`p_time_zone`。客户端传运行设备的 IANA 时区；数据库据此校验目标不早于今天。改期允许提前或推后，拒绝原日期及已完成任务；历史保留 from/to 日期，实际投入仍在原账本日期。三参数入口保持可调用，按 UTC 校验。

此迁移只替换函数、设置新重载权限，不执行历史数据更新或清理。应先部署迁移再发布新客户端；部署状态与本地验证分开报告。

本期不提供 Daily 未来展开、小时刻度、拖拽排程或外部日历同步。原 analytics 仍供洞察和报告使用。

## 验证

单元测试覆盖分组、密度、未知估时、周跨年及改期日期；浏览器测试覆盖新建、提前改期、完成、待安排转入和首页日期隔离，并输出截图和 axe 报告。数据库测试在事务内验证历史、账本与 RLS，结束回滚。

Playwright iPhone WebKit 属于浏览器自动化，不能替代真实 iPhone Safari/PWA；打包 Windows 应用和真实设备需分别验收。
