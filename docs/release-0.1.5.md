# Threadline 0.1.5

- 新增一级栏目「习惯」：一键记录真实起床、睡觉时间，并选择当天工作效率好／中／差。
- 支持周/月达标率、平均时间、作息趋势、效率日历及历史补录、修改、清除和恢复。
- 支持账号时区、起床目标和睡觉三个分界独立调整；睡觉与效率以 04:00 分日，保留原始时间和历史规则。
- 修复规则加载期间的暂时错误统计、失败草稿恢复、跨设备改归属后的旧缓存，以及洞察图表暗色提示文字对比度。

习惯数据库已先于客户端部署。此次版本提交只调整版本号及发布说明，业务代码与已完成 CI 的习惯版本一致。正式发布通过匹配版本 tag 的 Actions，检查 Preview/安装产物一致性、生产配置、安装包及更新文件校验和，上传后再次下载核对，成功后才公开。

Windows x64 安装包：`Threadline_0.1.5_x64-setup.exe`。0.1.2–0.1.4 安装版可通过「设置 → 关于 Threadline」检查更新、下载并确认重启。旧 0.1.1 或 Preview 目录版需手动运行安装包；覆盖原目录，不卸载或清理用户数据。

安装包、`.blockmap` 与 `latest.yml` 在同一 GitHub Release 发布。是否已公开以 [正式 Release](https://github.com/Doris619619/Threadline/releases/tag/v0.1.5) 为准。实体设备上保留登录的完整更新重启流程须与构建、校验和及启动 smoke 区分记录。
