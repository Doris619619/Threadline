# 皮卡经典视觉审查

目标是接近用户提供的原版游戏窗口，同时保留 Threadline 的导航、工作区和任务首屏。审查面向桌面浏览器、手机 PWA 与 Electron 共用前端；不将游戏主题改成系统默认外观。

## 结论与修正

- **高优先级：外框抢眼。** 逐个面板套金框、或沿整个工作区再套一圈长金边，都会与应用本身的边界重叠。根据用户标注，移除主工作区顶部横梁和两侧长金边；金色集中在小面积括号页签、选中细节及真正的模态窗口。奶油色底承载白色细边面板。
- **高优先级：深色底色杂乱。** 初稿的橄榄灰窗底、蓝灰面板与亮黄金框不协调。现统一为蓝灰色阶，使用独立哑金框和较低饱和的琥珀色选中态。背景比内容面板更暗，靠亮度区分层次。
- **中优先级：小字与装饰使用同一种亮橙。** 小字号操作改用深棕橙；亮橙限定在选中底色和图表。绿色只用于确认／完成，危险操作保留红色语义。家具与人物的粉蓝色保留在小面积插画中。
- **中优先级：装饰推低手机任务。** 移除额外外框与窗梁，保留原主区域的边距及底部导航安全区；隐藏原有工作区副说明、减少手机标题下方间距。测试比较切换前后的真实任务位置和宽度。
- **高优先级：菜单遮挡编辑窗。** 手机触摸悬停可能保留任务菜单，经典编辑窗提升到菜单之上；用真实命中点验证项目选择器不被遮挡。

以上修正依据 Color 的一致语义与明暗适配、Dark Mode 的层次和低光舒适性、Layout 的内容优先，以及 Typography 的字号与字重层次。参考：[Color](https://developer.apple.com/design/human-interface-guidelines/color)、[Dark Mode](https://developer.apple.com/design/human-interface-guidelines/dark-mode)、[Layout](https://developer.apple.com/design/human-interface-guidelines/layout)、[Typography](https://developer.apple.com/design/human-interface-guidelines/typography)、[Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)。

## 配色分工

| 用途       | 浅色             | 深色               |
| ---------- | ---------------- | ------------------ |
| 窗底       | 奶油黄 `#f8f4d0` | 蓝灰 `#292d36`     |
| 内容面板   | 暖白 `#fffef8`   | 蓝灰 `#30343e`     |
| 交替行     | 浅奶黄 `#f8f4d0` | 略亮蓝灰 `#383c45` |
| 主文字     | 黑棕 `#252514`   | 浅奶油 `#fff7d4`   |
| 操作文字   | 深棕橙 `#915000` | 柔金 `#e8c078`     |
| 选中底色   | 亮橙 `#ff9800`   | 琥珀 `#d6a653`     |
| 确认／完成 | 叶绿 `#4b700d`   | 灰绿 `#b1c991`     |

同一层级使用相同颜色；不为每张卡片分配额外底色。用户自定义项目颜色保持原意，不强制覆盖。选中、完成仍有文字、边框或勾选形状，不单靠颜色。

## 可读性实测

下表由当前 CSS 语义颜色按 sRGB 相对亮度计算；同时用真实页面 axe 检查继承样式和实际背景。

| 文字／背景             | 浅色对比度 | 深色对比度 |
| ---------------------- | ---------- | ---------- |
| 主文字／内容面板       | 15.36:1    | 11.57:1    |
| 次文字／内容面板       | 7.20:1     | 7.83:1     |
| 辅助字／交替行         | 5.46:1     | 5.43:1     |
| 操作文字／内容面板     | 6.20:1     | 7.26:1     |
| 确认按钮文字／绿色按钮 | 5.71:1     | 7.66:1     |
| 标签文字／选中底色     | 7.23:1     | 7.01:1     |

可读性指标用于排除看不清的问题，不代替审美判断。审美检查使用首页、规划、项目、洞察、节律、设置及装扮的真实渲染截图，核对底色一致性、装饰面积、层次、标题比例和视觉重心。执行结果与截图见 [验收记录](screenshots/classic/README.md)。

本轮为浏览器模拟和本机屏幕评审，尚未覆盖不同真实显示器、户外亮光、系统高对比模式及长时间个人使用感受；不将这些边界表述为已验证。
