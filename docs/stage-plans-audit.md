## 数据与兼容边界

- 阶段、日程和项目从同一个 Task 派生；安排、改期、完成及取消完成不复制任务，普通待安排只排除阶段关联项。
- 阶段状态按账号日期派生，结束当天仍进行中；过去保留任务、历史与编辑入口。隐藏可撤销，删除阶段在同一事务内解除归属并保留任务。
- 检查 owner RLS、同账号复合外键、日期约束、受检版本、稳定 ID、项目状态锁、事务失败回滚、RPC 权限和 Realtime 配置。
- 阶段关联回收站任务免清理，普通任务仍按原 30 天规则清理；工作站、投入账本、Daily、项目管理和洞察沿用原数据路径。
- 账号查询键隔离；账号切换期间旧回包不写入新账号。阶段加载失败仅影响阶段区域。

## 验证依据

本机 90 文件 452 项单元/组件、29 项隔离 PostgreSQL 合同、SQL 静态合同、全仓 lint、类型与 Web/nonce CSP 构建通过。完整 Preview 15 项覆盖桌面、320px 和 iPhone WebKit，包含任务记录数/ID、项目筛选、刷新持久化、Daily 与收尾、长标题、两步返回、短视口、明暗主题和无障碍检查。

最终合并还要求同一提交的 GitHub Web 全量浏览器、真实 Supabase 双客户端、Preview 和 Windows Electron 门禁全部通过；结果与运行链接记录在 PR #52。生产发布先迁移后客户端，安装包由 tag 流水线验证后公开。

这些证据覆盖自动化可验的规则与运行路径，不保证没有任何潜在缺陷。实体 iPhone 软键盘/PWA 及用户 Windows 设备上的安装体验仍需要人工验收。
