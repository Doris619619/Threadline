# Threadline 0.1.10

- 两个已有账号通过邀请码绑定好朋友或情侣。生成、查看邀请码均不解锁目标功能，接受邀请后双方才进入同一个空间；每人同时只能绑定一人。
- 好朋友使用「我们的自习室」，情侣使用「同频」。关系变更由另一人确认；解除后未完成目标结束，旧空间仅原成员可读，新对象不能读取旧记录。
- 各自立 flag、通过微信发送成果，由对方验收。要求补充后可再次提交，通过后进入回忆；情侣的首次鼓励、通过和惊喜按规则累计好感度。
- 验收绑定具体提交事件，防止后台刷新期间把旧成果当成新成果通过。修复窄屏表单溢出、离线修改后重试受阻，以及异常截止时间导致渲染失败。

## 部署与验证

先按顺序应用 `202609280001_together.sql`、`202609300001_together_review_safety.sql`，核验 RLS、RPC 权限和 Realtime，再合并客户端并推送 `v0.1.10`。迁移增加独立业务表和安全约束，不清理已有个人任务数据。

绑定回归覆盖好朋友和情侣两种初始关系、接受前不解锁、双向关系变更确认、解除后重新锁定，以及数据库拒绝未绑定写入、自绑定和跨空间访问。另保留成果版本、离线重试、异常日期及窄屏回归。

Windows Release 通过正式流水线构建和校验安装器、blockmap、`latest.yml` 后公开。自动化不替代实际双设备账号体验、Windows 安装升级和真机 iPhone PWA 验收。本机真实云配置 EXE smoke 曾在多显示器登录窗口垂直居中断言失败（偏差 4 像素），该项不计为通过。
