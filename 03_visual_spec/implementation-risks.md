# Implementation Risks

## 高风险

| 项目            | 描述                                          | 建议方案                                   |
| --------------- | --------------------------------------------- | ------------------------------------------ |
| 假交互          | 参考图含仓库不存在的日/周、新建日程和账户编辑 | 不渲染这些入口                             |
| Web 原生控制    | 现有全窗口控制在 Web 为 no-op                 | 用单一 `isNativeDesktop` capability gating |
| 全局 token 回归 | Home、紧凑桌面和移动端共享 token              | 截图覆盖所有受影响视图                     |

## 中风险

| 项目         | 描述                           | 建议方案                                   |
| ------------ | ------------------------------ | ------------------------------------------ |
| 账户 popover | 静态图无法给出键盘行为         | 使用 disclosure，不滥用 menu role          |
| 热力配色     | 截图展示事件蓝，不对应真实热力 | 基于 accent 定义 heat tokens，保留文字标签 |

## 需脚本验证

| 项目         | 当前估算值     | 验证方式                                         |
| ------------ | -------------- | ------------------------------------------------ |
| 颜色与对比度 | 从 PNG 估算    | Playwright 截图与 contrast 检查                  |
| 响应式布局   | 桌面 bbox 估算 | 1440px、390px 截图                               |
| 视觉回归     | 未执行         | Calendar、Settings、Home、Mini、Workstation 截图 |

## 低置信度汇总

| 项目         | 阶段            | Confidence | 影响范围           |
| ------------ | --------------- | ---------- | ------------------ |
| 精确字体族   | typography      | 0.55       | 采用现有系统字体栈 |
| popover 阴影 | color/elevation | 0.67       | 账户 disclosure    |
